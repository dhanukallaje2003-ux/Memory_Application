# Memory Dump Application

Memory Dump Application is a React and TypeScript web app for emotional wellness journaling. It includes a conversational companion UI, a memory journal, and a mood tracking dashboard.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Recharts

## Getting Started

```sh
npm install
npm run dev
```

The development server runs on `http://localhost:8080`.

## Available Scripts

- `npm run dev` - start the development server
- `npm run build` - create a production build
- `npm run preview` - preview the production build
- `npm run lint` - run ESLint
- `npm test` - run tests with Vitest
